# Audio System Enhancer

A native Android sound processing engine designed using Android's `DynamicsProcessing` API.

### Features
- Hardware-level Pre-EQ tuning (+5.5 dB at 60Hz for sub-bass punch).
- Multi-band compression for tight dynamics.
- High-frequency sparkle filter at 12kHz.
- Material UI switch and control sliders.

### Requirements
- Minimum Android Version: Android 9 (API 28)
- Target: Android 14 / Android 15 (API 35)
